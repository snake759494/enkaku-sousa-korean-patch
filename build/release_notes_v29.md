## 적용 방법

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
원본 크기   739,835,904 바이트
원본 MD5    9f9bb5eec3d2c37f184955b591923e1c
```

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v2.9.xdelta Enkaku_Korean.iso
```

```
결과 크기   739,835,904 바이트 (원본과 동일)

```

이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오.

## 시스템 메뉴

```
システムメニュー → 시스템 메뉴
情報一覧     → 정보 일람        尋問一覧   → 심문 일람
セーブ       → 세이브           ロード     → 로드
人物関係図   → 인물 관계도       設定       → 설정
タイトルへ戻る → 타이틀로        辞典・解説 → 사전·해설
情報集約     → 정보 정리
```

두 텍스처 모두 **항목마다 선택 상태와 비선택 상태를 각각 들고 있어서**, 흰 글자와 회색 글자를 짝으로 맞춰 넣었습니다.

## 두 가지 처리

**투명 배경과 불투명 패널을 구분해야 했습니다.** v2.8의 챕터 제목은 장면 위에 바로 얹히는 투명 배경이라 상자를 투명으로 지웁니다. 그런데 시스템 메뉴는 **검은 패널 위**에 있어서, 같은 방식으로 지우면 패널에 구멍이 뚫립니다. 상자 안에 투명 화소가 거의 없으면 배경이 있다고 보고, 그 배경색으로 지우도록 했습니다.

**패널이 세로 그라데이션**이라 단색으로 채우니 네모가 드러났습니다. 행마다 그 행의 배경색을 따로 잡아 채웁니다.
