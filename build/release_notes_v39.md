# v3.9 — 실기 ISO 로더 호환성 패치

## 적용 방법

직접 덤프한 원본 일본판 ISO에만 적용합니다.

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v3.9.xdelta Enkaku_Korean_v3.9.iso
```

## 실기 구동 회귀 수정

v3.8 패처는 `0001`의 모든 16바이트 블록 식별자를 MD5로 다시 계산했습니다. 그러나 원본 게임은 중복 리소스 블록에 `61 0d 0a`로 시작하는 opaque 식별자를 사용합니다. 이 12개 식별자를 MD5로 바꾸면 ISO 크기와 압축 해제에는 문제가 없어도 실기 리소스 로더가 중복 블록을 찾지 못할 수 있습니다.

v3.9에서는 원본 식별자가 실제 블록 MD5와 일치하는 47개 블록만 새 내용에 맞춰 MD5를 갱신하고, 나머지 12개 opaque 식별자는 원본 16바이트를 그대로 보존합니다. 압축된 블록 길이·헤더 위치·후속 LBA는 유지됩니다.

## 검증 결과

- ISO9660 구조: 26개 파일, 5개 폴더, 361,248섹터, `UMD_DATA.BIN` present, `PARAM.SFO` bootable
- ISO 크기·PVD·디렉터리 레코드·파일 LBA 불변
- `EBOOT.BIN`, `BOOT.BIN`, `PARAM.SFO`, `UMD_DATA.BIN` 바이트 불변
- `0000`·`0001`만 원본 ISO의 기존 레코드 범위 안에서 변경
- `0000` LZ11 스트림 2개 및 `0001` 대상 59개 블록 해제 검증 통과
- `0001`: MD5 식별자 47개 갱신, opaque 식별자 12개 보존
- 대사 런타임 샘플 282/282 확인
- 선택지 178행: 일본어 잔존 0건, 정답 선택 매핑 확인
- xdelta 재적용 결과가 릴리즈 ISO와 SHA-256 일치

`work/verify_hardware_iso.py`로 위 ISO·아카이브 검사를 재현할 수 있습니다. 실제 PSP 기기에서의 최종 확인은 기기/CFW 조합이 필요하므로, 수정된 ISO는 CFW ISO 로더에서 메모리스틱·SD 카드의 `/ISO` 폴더에 넣어 실행하십시오. 정품 펌웨어만으로는 수정 ISO를 실행할 수 없습니다.
