## 적용 방법

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
원본 크기   739,835,904 바이트
원본 MD5    9f9bb5eec3d2c37f184955b591923e1c
```

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v2.1.xdelta Enkaku_Korean.iso
```

```
결과 크기   739,835,904 바이트 (원본과 동일)
결과 MD5    79d3ae1631cdbf755abc26b879bdab97
```

이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오. v1.x나 v2.0 결과물에 덧씌우면 안 됩니다.

## v2.1에서 고친 것

### HUD 버튼 17개

화면 아래·위에 항상 떠 있는 버튼과 표시입니다.

```
메뉴   다음   선택   결정   뒤로   이동   상세   없음   사전
스크롤   남은   오전   정오   오후   부재   정기휴일
```

이 텍스처는 여러 단어가 한 장에 붙어 있고, 글자가 서로 맞닿아 있어 픽셀 간격으로는 단어 경계를 가를 수 없었습니다. 그래서 v1.x에서는 손대지 못했고, 잘못 그리면 옆 단어를 지우기 때문에 추측으로 진행하지 않았습니다.

이번에는 눈금을 넣어 렌더링해 **모든 글자가 16픽셀 격자에 정확히 놓여 있다**는 것을 확인했습니다. 독립적으로 떨어져 있던 `メニュー`가 64–127로 정확히 네 칸을 차지하는 것이 그 격자를 뒷받침합니다. 경계가 계산으로 나오니 병합돼 보이던 구간도 안전하게 나눌 수 있었습니다.

버튼 글리프(Ⓡ Ⓛ ○ △ ✛)와 커서 그림은 대상에서 제외했으므로 그대로입니다.

## 아직 남은 것

| 항목 | 사유 |
|---|---|
| 타이틀 메뉴 (`最初から` 등)와 `START` | 해당 텍스처가 `USRDIR/0000`에 없습니다. 다른 파일을 더 찾아야 합니다 |
| 신문 기사 2장, 인물 이름표 20여 장, 수첩 1장 | 세로쓰기·손글씨 등 개별 작업 필요 |

HUD의 한글은 원본이 두꺼운 비트맵 글꼴이라 굵기가 조금 가늡니다.
