신문 기사 두 장의 표제를 한글화했습니다.

## 적용 방법

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
원본 크기   739,835,904 바이트
원본 MD5    9f9bb5eec3d2c37f184955b591923e1c
```

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v2.6.xdelta Enkaku_Korean.iso
```

```
결과 크기   739,835,904 바이트 (원본과 동일)
결과 MD5    aa53b6c2c0fe08aaf2254a06729e1ba8
```

이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오.

## 신문 표제

```
白川一朗代表殺害              → 시라카와 대표 피살
高級バーで起きた悲劇          → 고급 바에서 일어난 비극
住宅業界のみならず、          → 주택업계뿐 아니라
  日本経済へ影響懸念             일본 경제에 파장 우려
斉藤容疑者の友人・            → 사이토 용의자의 친구
  沼崎栄太郎氏談                 누마사키 에이타로 씨
```

신문은 **세로쓰기**입니다. 그래서 한글도 세로로, 원문과 같은 단에, 같은 크기(13~16px)로 넣었습니다. 오른쪽 단부터 왼쪽으로 읽는 순서도 그대로입니다.

**인물이 신문 앞에 서 있습니다.** 인물은 종이(밝기 68)나 활자보다 훨씬 어두워서(밝기 35 미만) 값으로 구분됩니다. 이 부분에는 글자를 쓰지 않도록 해서, 원래 일본어가 가려지던 자리에서 한글도 똑같이 가려집니다. 글자 중간에서 잘리는 것까지 같습니다.

`沼崎栄太郎`의 `栄`은 16픽셀에서 `晋`으로 보입니다. 이 게임에는 `晋太郎`라는 다른 인물이 있어서 헷갈릴 수 있는데, 스크립트가 정리해 줍니다 — `沼崎` 다음에 `栄太郎`가 21번 오고 `晋太郎`는 한 번도 오지 않습니다.

## 손대지 않은 것과 그 이유

**신문 본문**은 일본어 그대로 두었습니다. 약 8픽셀로 조판되어 있어서 **일본어로도 한글로도 글자로 읽히지 않는 크기**입니다. 읽을 수 없는 지면을 다른 방식으로 읽을 수 없게 만드는 일이라, 지면 질감만 망가뜨릴 위험이 있습니다.

**수첩(tex0265)**도 그대로 둡니다. 손글씨가 4~6픽셀로 그려져 있어 **원문 자체가 판독되지 않습니다.** 무엇이라 적혀 있는지 읽을 수 없으므로 옮길 대상이 없고, 지어내지 않았습니다.

## 아직 남은 것

| 항목 | 사유 |
|---|---|
| 타이틀 메뉴 (`最初から` 등)와 `START` | **찾지 못했습니다.** USRDIR 전 파일(404 MB짜리 0012 포함)에 텍스처 스트림이 없고, 실행 파일에도 Shift-JIS·UTF-8·UTF-16 어느 형태로도 문자열이 없으며, 스크립트에도 없습니다 |
| 신문 본문 · 수첩 | 위 사유 |
| 반복 장면 22곳 | 어느 번역이 맞는지 기계적으로 판정되지 않아 남겼습니다 |
