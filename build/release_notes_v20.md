## 적용 방법

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
원본 크기   739,835,904 바이트
원본 MD5    9f9bb5eec3d2c37f184955b591923e1c
```

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v2.0.xdelta Enkaku_Korean.iso
```

```
결과 크기   739,835,904 바이트 (원본과 동일)
결과 MD5    9f4cfdafcedfefd4f2ae35519da182df
```

이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오. v1.x 결과물에 덧씌우면 안 됩니다.

## 무엇이 달라졌는가

### 대사 전면 재번역

v1.x의 대사는 초벌 기계 번역이 상당 부분 남아 있었습니다. 문장이 잘리거나, 띄어쓰기가 사라지거나, `彼`가 사람 이름처럼 `아야`로 나오는 등의 문제가 있었습니다.

v2.0은 복원된 일본어 원문을 기준으로 9,626행 전체를 다시 옮긴 것입니다.

| 검증 항목 | 결과 |
|---|---|
| 원문/번역 인덱스 일치 | 9,626 / 9,626 |
| 중복·순서 이상 | 0 |
| 잔여 가나·한자·대체문자·호환자모 | 0 |
| 인코딩 실패 | 0 |
| 대사창 폭 초과 | 0 |
| 텍스트 블록 검출 | 8,822 / 8,822 |
| 참조 재작성 | 33,371 / 33,371 (충돌 0) |

폰트는 실제로 쓰이는 993자로 다시 구성했습니다.

### 이미지

v1.0~v1.3에서 작업한 내용이 그대로 들어 있습니다.

- 설정 화면 — 제목·설명문·항목명 한글화, 회색 배경 글씨와 노란색 선택 글씨 정렬 일치
- 타이틀 로고 — 원격수사 / 진실을 향한 23일간
- 날짜 카드 22장, 기소 카운트 9장, 조사 질문 63장, 메뉴·설정·챕터명, 장소명, 인물 관계, 시스템 메시지, 명함
- HUD 아틀라스 일부 (`メニュー`→메뉴, `詳細`→상세, `なし`→없음)

## 아직 남은 것

| 항목 | 사유 |
|---|---|
| HUD의 `次へ`·`選択`·`戻る`·`決定` | 글자가 서로 붙어 있어 단어 경계를 픽셀로 가를 수 없습니다. 잘못 그리면 옆 단어를 지웁니다 |
| 타이틀 메뉴 (`最初から` 등)와 `START` | 해당 텍스처가 `USRDIR/0000`에 없습니다. 다른 파일을 더 찾아야 합니다 |
| 신문 기사 2장, 인물 이름표 20여 장, 수첩 1장 | 세로쓰기·손글씨 등 개별 작업 필요 |

HUD에 넣은 한글은 원본이 두꺼운 비트맵 글꼴이라 굵기가 조금 가늡니다.
