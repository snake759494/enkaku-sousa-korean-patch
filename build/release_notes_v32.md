시스템 메시지 여섯 장의 **가독성을 고치고**, 그 과정에서 **번역문이 엉뚱한 화면에 붙어 있던 것**을 찾아 바로잡았습니다. [이슈 #4](https://github.com/snake7594/enkaku-sousa-korean/issues/4) 제보 반영입니다.

## 적용 방법

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
원본 크기   739,835,904 바이트
원본 MD5    9f9bb5eec3d2c37f184955b591923e1c
```

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v3.2.xdelta Enkaku_Korean.iso
```

```
결과 크기   739,835,904 바이트 (원본과 동일)
결과 MD5    f7891832ec2b0a86ca2eed068e40a47f
```

이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오.

## 가독성

`설치 데이터를…` 두 줄이 가늘고 끊겨 보인다고 알려주셨습니다. **네 배로 크게 그린 뒤 줄여서** 만들고 있었습니다. 큰 글자를 매끄럽게 만들 때는 맞는 방법이지만, 14픽셀 글자에는 정반대입니다 — 축소 필터가 획 하나를 두 픽셀에 반씩 나눠 놓아서, 화면에서 가늘고 끊겨 보입니다.

**최종 크기로 바로 그리도록** 바꿨습니다. 획이 한 픽셀에 온전히 들어갑니다. 그 크기에서 버티지 못하는 명조체 대신 고딕체를 씁니다.

## 번역문이 다른 화면에 붙어 있었습니다

고치는 김에 일본어 원문과 나란히 놓고 보니, **여섯 장 중 다섯 장이 서로 다른 화면의 번역을 달고 있었습니다.**

| 텍스처 | 원문 | 지금까지 | 바로잡음 |
|---|---|---|---|
| 0429 | `インストールデータが破損しています` | 저장되어 있지 않습니다 | **손상되었습니다** |
| 0430 | `ロードできませんでした` | 손상되었습니다 | **불러올 수 없었습니다** |
| 0431 | `セーブされています` | 320KB 이상의 빈 용량이… | **저장되어 있습니다** |
| 0432 | `セーブされていません` | 불러올 수 없었습니다 | **저장되어 있지 않습니다** |
| 0435 | `320KB以上の空き容量が必要です` | 저장되어 있습니다 | **320KB 이상의 빈 용량이…** |

실제로 뜨는 상황과 문구가 어긋나 있었습니다. 이제 각 화면이 자기 문구를 답니다.
