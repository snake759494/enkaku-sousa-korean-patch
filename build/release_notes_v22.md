## v2.2에서 고친 것

인물 관계도와 자료 화면에 나오는 이름표입니다.

```
水無月葵   → 미나즈키 아오이      三浦正信 → 미우라 마사노부
神崎茜     → 간자키 아카네        マスター → 마스터
近藤克美   → 콘도 가쓰미          新城法子 → 신조 노리코
吉本清香   → 요시모토 사야카      白川安代 → 시라카와 야스요
水谷朝露   → 미즈타니 아사츠유    七芝伊月 → 나나시바 이즈키
吉本ユミ   → 요시모토 유미
```

`三浦正信`·`水谷朝露`·`新城法子`는 대사에서 쓰이는 표기와 맞췄으므로, 이름표와 대사가 같은 이름으로 읽힙니다.

두 이름은 읽기를 확정할 수 없어 통용되는 쪽을 골랐습니다. `吉本清香`는 사야카/기요카, `七芝伊月`는 이즈키/이츠키가 모두 가능합니다. 게임에서 다른 읽기로 불리는 것을 발견하시면 알려주십시오.

## 아직 남은 것

| 항목 | 사유 |
|---|---|
| 타이틀 메뉴 (`最初から` 등)와 `START` | **찾지 못했습니다.** USRDIR 전 파일(404 MB짜리 0012 포함)에 텍스처 스트림이 없고, 실행 파일에도 Shift-JIS·UTF-8·UTF-16 어느 형태로도 문자열이 없으며, 스크립트에도 없습니다. 다른 형식으로 저장돼 있어 추가 조사가 필요합니다 |
| 신문 기사 2장 | 세로쓰기 밀집 텍스트 |
| 수첩 1장 | 손글씨 |
| 이름표 나머지 | 검출 기준에 걸리지 않은 것이 더 있을 수 있습니다 |
