## 제보 확인

대사 스트림의 선택지와 정답 후보는 v3.6 실행 데이터에서 이미 한글로 들어가 있었습니다. 이번 릴리즈에는 같은 문제가 다시 생기지 않도록 원문과 번역 TSV의 괄호 선택 행 178개를 자동 감사하는 `work/audit_choices.py`를 추가했습니다.

검수 결과:

```
choice rows: 178
Japanese residuals: 0
answer mappings:押してみる/押さない -> 눌러 본다/누르지 않는다
```

실제 화면에서 일본어로 남아 있던 것은 선택지 데이터와 별도로 저장된 정적 UI였습니다. v3.7은 이 누락분을 패치합니다.

## 이번 패치

- 시스템 메뉴의 `セーブ` 2곳을 `저장`, `ロード` 2곳을 `불러오기`로 수정했습니다.
- `0001` 조사 화면 컨테이너의 확정 판독 정적 라벨 24개 레코드를 수정했습니다. 512×32 레코드 4개에는 `시라카와 가문 가족사진`, `미즈타니 탐정사무소`, `수집 증거품 케이스`, `현장 사진 검증 기록`을 넣었습니다.
- 256×32 레코드에는 `구치소`, `취조실`, `미즈타니 탐정사무소`, `시라카와 가문 가족사진`, `미야카미 대학 부속 병원`, `누마사키 사무소`, `신토 택시 센터`, `게임 센터`, `피해 현장`, `포레스트하임`, `아파트 1층·2층`, `뒤로`를 넣었습니다. 중복 레코드는 같은 번역으로 처리했습니다.
- 고정 크기 레코드의 압축 길이와 레이아웃은 유지했습니다. `0000`과 `0001`은 모두 원본과 같은 크기이며 원래 LBA에 제자리 교체됩니다.

## 검증

- `0000` 스트림 0·1 압축/해제 왕복 및 사운드뱅크·후행 데이터 보존 통과
- 최종 ISO에서 대사 288/288 샘플의 번역 인코딩 확인
- 선택지 178행 일본어 잔존 0건
- 최종 ISO의 `0000`·`0001` 바이트가 빌드 산출물과 일치
- 최종 ISO 크기 739,835,904바이트
- 에뮬레이터는 실행하지 않음

## 아직 손대지 않은 것

판독이 확실하지 않은 일부 `0001` 4bpp 라벨(`裁判所` 등), 시작 면책 문구, 챕터 세로 시트, HUD 조각, 신문·수첩·간판처럼 그림에 박힌 일본어는 이번 버전에서 변경하지 않았습니다.
