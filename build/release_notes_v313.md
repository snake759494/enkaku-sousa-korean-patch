## v3.13 — 최종본: 깨진 4bpp 이미지 복원, 저장소 이관

새 계정 `snake759494`의 저장소로 이관한 최종본입니다. v3.12를 PPSSPP에서 부팅해 확인하다가 발견한 문제 하나를 고쳤습니다.

### 원인

v3.8부터 v3.12까지 `0001` 아카이브의 4bpp 레코드 25개 — 시작 면책 문구 1장과 조사 화면 장소 라벨 24개 — 를 한국어로 다시 썼습니다. 그런데 이 4bpp 픽셀 배치는 끝내 확정되지 않은 채로 인코더에 들어갔고, 게임은 그 결과를 **획이 흩어진 형태**로 그립니다. v3.12를 부팅한 첫 화면(면책 문구)이 바로 그 상태였습니다.

또 그 면책 문구의 번역 자체가 원문과 반대였습니다. 원문은 `この物語はフィクションです`(이 이야기는 픽션입니다)인데 `논픽션`으로 들어가 있었습니다.

### 조치

- 4bpp 레코드 25개를 **원본 그대로 되돌렸습니다.** 화면에는 일본어가 다시 나오지만 읽을 수 있습니다. 판독은 되지만 정확히 되쓸 수 없는 것은 덮어쓰지 않는다는 이 프로젝트의 원칙으로 돌아간 것입니다.
- 나머지는 v3.12와 같습니다: 대사 9,626행, `0000` 텍스처, 튜토리얼 21쪽·장면 배너 12장·CERO 안내(모두 8bpp, 왕복 검증 통과), `PARAM.SFO` 5.00, 원래 LBA 제자리 교체, 런타임 4바이트 정렬.

- `verify_hardware_iso.py`: ISO9660/LBA/부팅 파일 불변, `0000` 스트림 2개, `0001` 34블록(MD5 26·opaque 8) 통과
- 대사 왕복: 294/294 샘플 확인
- xdelta 재적용 결과 MD5가 배포 ISO와 일치
- PPSSPP 1.17.1 부팅: 로고 → 면책 문구(원본 일본어, 정상 표시) → 설치 데이터 안내(한국어) 확인

### 적용 방법

원본 일본판 ISO(MD5 `9f9bb5eec3d2c37f184955b591923e1c`)에 한 번만 적용합니다.

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v3.13.xdelta Enkaku_Korean_v3.13.iso
```

실기(PSP-1000/3000 CFW, Vita Adrenaline)에서는 결과 ISO를 ISO 로더의 `/ISO` 폴더에 넣어 실행하십시오. 물리 장치는 이 작업 환경에 연결되어 있지 않아 실기 동작을 직접 확인하지는 않았습니다.
