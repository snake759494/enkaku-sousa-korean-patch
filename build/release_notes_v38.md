## 이슈 #5 — 타이틀·시작 면책 문구

`0001`의 실제 시작 면책 화면(`0x53b800`, 1024×256 4bpp)을 확인하고 다음 문구를 한국어로 교체했습니다.

```
이 게임의 이야기는 논픽션입니다.
등장하는 인물, 지명, 단체명, 상품명 등은 실제 존재하는 것과
전혀 관계가 없습니다.
```

기존 v3.7에서 번역했던 CERO 안내 화면과 조사 화면 라벨도 유지됩니다. `최초부터`·`계속부터`·`데이터 인스톨`은 실행 파일·0000·0001~0004의 패치 가능한 문자열/이미지로 존재하지 않는다는 점을 확인했습니다. 따라서 이슈 본문의 해당 문자열은 현재 게임 리소스에 적용할 대상이 아니며, 실제로 존재하는 시작 안내만 이번 버전에서 처리했습니다.

## 이슈 #6 — v3.3/v3.4 화면 깨짐

원인은 v3.3에서 번역 스트림과 서로 다른 글리프 슬롯표를 사용한 회귀였습니다. v3.5에서 올바른 슬롯표로 고쳐졌고, v3.8도 같은 검증된 `0000` 스트림을 사용합니다.

최종 ISO 검증:

```
대사 288/288 샘플: 인코딩된 번역 확인
선택지 178행: 일본어 잔존 0건
0000·0001: 빌드 산출물과 ISO 구간 바이트 일치
ISO 크기: 739,835,904바이트
```

## 배포 검증

- 원본 ISO에서 xdelta를 다시 적용한 결과가 v3.8 ISO와 SHA-256 일치
- `0000` 스트림 0·1 압축/해제 왕복, 사운드뱅크·후행 데이터 보존 통과
- `0001` 59개 레코드/59개 블록 패치 및 원본 크기 유지
- 에뮬레이터는 실행하지 않음
