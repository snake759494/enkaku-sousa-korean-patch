## v3.18 — 이슈 #5 자잘한 문제 수정

v3.17에서 달라진 점입니다. v3.13~v3.17의 세이브를 그대로 이어서 쓸 수 있습니다. 대사 위치는 바이트 단위로 v3.17과 같습니다.

### 1. 하단 대사창에서 코우지 대사가 버튼 바를 덮던 문제
- v3.15에서는 코우지가 늘 오른쪽 위 창(8줄)에서 말한다고 보고 그의 대사를 제외했습니다. 제보 화면처럼 코우지도 하단 창(이름+3줄)에서 말하는 장면이 있었습니다.
- 4줄 이상이던 【코우지】 대사 471행을 모두 33칸×3줄에 맞췄습니다. 133행은 줄바꿈만 다시 했고, 나머지는 원문 의미·호칭·말투를 지키며 문장을 다듬었습니다.
- 이제 이름이 붙은 모든 대사가 본문 3줄 이내입니다.
- 다듬는 과정에서 원문과 어긋난 번역도 바로잡았습니다. 예를 들어 脳死→뇌사, 1週間→일주일, 昼過ぎ→점심 지나, 姉妹→자매입니다.

### 2. 나나시바가 유치장을 나가는 장면 등에서 이름표가 안 나오던 문제
- 번역 과정에서 26행이 화자 이름표(【코우지】【나나시바】【구치소 직원】)를 잃었습니다. 그중 24행에 이름표를 되살렸습니다.
- 「간다.」, 「응, 또 봐!」 두 줄은 원래 길이(12·14바이트)가 이름표보다 짧습니다. 세이브 호환을 깨지 않고는 이름표를 넣을 수 없어 그대로 두었습니다.

### 3. 날짜가 「구속 2 일일」로 나오던 문제
- 상단 HUD 「拘束 N 日目」의 「目」 칸을 「日」로 잘못 기록해 「일일」로 그려졌습니다. 이제 「구속 N 일째」로 나옵니다.

### 4. 인물 관계도
- 이름판은 원래 카드 폭(약 88px) 안에 글자를 넣고 원본의 흰 띠를 다시 칠합니다. 이름이 카드 밖으로 튀어나오거나 잘리지 않습니다.
- 관계 라벨(상사와 부하 등)을 원본처럼 흰 글씨로 다시 그렸습니다. 어두운 관계도에서도 읽힙니다.

### 5. 「남은 1つ」
- 심문 화면 하단 「残り１つ」의 「つ」가 번역되지 않았습니다. 「남은 1개」로 고쳤습니다.

### 확인
- `verify_runtime_alignment.py`, `verify_dialogue.py`(40/40), `verify_hardware_iso.py --system-version 5.00 --plain-executable` 통과.
- PPSSPP에서 이전 세이브 불러오기, 「구속 2 일째」, 심문 화면의 「남은 1개」를 확인했습니다. 인물 관계도는 확인한 시점(2일차)에 아직 잠겨 있어, 텍스처 미리보기로 확인했습니다.

### 이번에 고치지 못한 것
- 장소 이동 때 글자가 겹쳐 보이는 화면은 재현하지 못했습니다. 장소 이름 문자열 자체에는 문제가 없습니다. 옛 장소와 새 장소 이름이 교차하는 연출 중간이 찍혔을 가능성이 있어 이슈에서 확인을 요청했습니다.
- 「해설」 탭 도움말 그림(4bpp 이미지)은 아직 일본어입니다.
