인물 이름표 7장을 추가로 한글화하고, 어머니의 이름을 바로잡았습니다.


이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오.

## 이름표 7장 추가

v2.2의 검출 기준은 잉크를 너무 많이 요구해서, 세 글자짜리 짧은 이름이 걸리지 않았습니다. 기준을 낮춰 7장을 더 찾았습니다.

```
白川悟     → 시라카와 사토루    白川一朗   → 시라카와 이치로
斉藤佳代   → 사이토 가요        白川真二   → 시라카와 신지
斉藤志朗   → 사이토 시로        白川美佐恵 → 시라카와 미사에
```

## 어머니의 이름: 가쓰요 → 가요

지금까지 대사에서 `가쓰요`로 나오던 광지의 어머니는 **`사이토 가요`**입니다. 52개 대사를 고쳤습니다.

이 이름은 원래 확정이 어려웠습니다. 게임에 나오는 유일한 후리가나가 `斉《お》藤《ふ》佳《く》代《ろ》`, 즉 "오후쿠로(어머니)"라고 읽는 말장난이라서, 후리가나가 한자 읽기를 알려주지 않기 때문입니다.

**이름표가 그림이라는 점이 근거가 됐습니다.** 그림에는 글자표가 개입하지 않으므로 거기 적힌 `斉藤佳代`가 곧 정답입니다. 글리프를 직접 그려서 판독한 기록도 같은 글자를 가리키고 있었습니다.

## 알게 된 것 — 다음 버전에서 고칠 부분

이 이름을 추적하다가 원문 쪽 문제를 하나 찾았습니다.

글자표를 만들 때 두 가지 방법을 썼습니다. **글리프를 실제로 그려서 눈으로 읽은 것**과, 그보다 앞서 **문맥으로 추정한 것**입니다. 원문을 만드는 과정에서 뒤쪽(추정)이 앞쪽(판독)을 덮어쓰고 있어서, **175개 글자가 추정값으로 되돌아가 있었습니다.**

이름표로 검증했습니다. 이름표에 나오는 이름을 원문에서 찾았을 때,

| | 판독값 | 추정값 |
|---|---|---|
| `白川真二` | 61회 | 0회 |
| `斉藤佳代` | 29회 | 0회 |
| `水無月葵` | 7회 | 0회 |
| `吉本清香` | 2회 | 0회 |

**4대 0입니다.** 반대로 나온 이름은 하나도 없습니다.

고치면 이런 것들이 제자리를 찾습니다.

```
真の他人      → 赤の他人      (생판 남)
彼女の係き待ち → 彼女の動き待ち
引き企める    → 引き締める     (후리가나 《し》가 締를 가리킵니다)
観何度物      → 観葉植物
白川不係産    → 白川不動産
```

원문 9,626행 중 **2,712행**이 바뀝니다. 그 행들의 번역은 틀린 원문을 보고 만들어진 것이므로 다시 옮겨야 합니다. 작업 중입니다.
